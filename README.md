# Cos'é LSduL?
La Storia di un Labirinto (LSduL) é un piccolo RPG che introduce e prepara la scena per LSduL.part2;  
Questa prima parte usa il terminale per la grafica con codici ANSI e disegni ASCII. [I don't speak italian!](#what-is-tsoal)



















# What is TSoaL?
The Story of a Labyrinth (TSoaL) is a small RPG introducing and setting up the stage for TSoaL.part2;  
This first part uses the terminal to display graphics with ANSI escape codes and ASCII art.
